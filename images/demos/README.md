# Demo Project Screenshots

This directory contains screenshots for demo projects displayed on the demos.html page.

## Adding Screenshots

1. Take a screenshot of your demo application (recommended size: 600x400px)
2. Save it here with a descriptive name (e.g., `recipe-bot.png`, `sound-monitoring.jpg`)
3. Update `demos.html` to reference your new image:
   ```html
   <img src="./images/demos/your-image.png" alt="Project Name">
   ```

## Recommended Screenshot Tools

- **macOS**: Cmd+Shift+4 for selection screenshot
- **Windows**: Win+Shift+S for snipping tool
- **Linux**: GNOME Screenshot or import command
- **Browser DevTools**: Use the device toolbar for responsive screenshots

## Tips for Great Screenshots

- Use high-quality PNG or JPG formats
- Show the main interface/features
- Keep file sizes reasonable (< 500KB)
- Use consistent dimensions across all screenshots
- Consider adding a subtle border or shadow
